# 🧮 Roni's PRO — প্রিমিয়াম ক্যালকুলেটর অ্যাপ

আধুনিক আইক্যচিং অ্যানিমেশন সহ মোবাইল-ফার্স্ট প্রিমিয়াম ক্যালকুলেটর।

## ✨ ফিচার
- **প্রিমিয়াম ডিজাইন** — গ্লাসমরফিজম + অরোরা/নিয়ন ব্যাকগ্রাউন্ড
- **ডার্ক ও লাইট থিম** — স্মুথ টগল, পছন্দ সেভ থাকে
- **হিস্ট্রি প্যানেল** — আগের হিসাবগুলো ট্যাপ করে আবার ব্যবহার করা যায় (localStorage-এ ৫০টি এন্ট্রি)
- **অ্যানিমেশন** — স্প্রিং বাটন প্রেস, রিপল ইফেক্ট, রেজাল্ট পপ, এররে ডিসপ্লে শেক
- **হ্যাপটিক ফিডব্যাক** — মোবাইলে ভাইব্রেশন (সাপোর্ট থাকলে)
- **কীবোর্ড সাপোর্ট** — ডেস্কটপে নাম্বার/অপারেটর কী দিয়ে ইনপুট
- **নিরাপদ ইঞ্জিন** — `eval()` ছাড়া নিজস্ব পার্সার; ডিভাইড-বাই-জিরো হ্যান্ডলিং

## 📱 ফোনে চালানো
1. `index.html` ফাইলটি ফোনে নিন এবং Chrome/Safari-তে খুলুন
2. ব্রাউজার মেনু থেকে **"Add to Home Screen"** দিন — নেটিভ অ্যাপের মতো ফুল-স্ক্রিনে চলবে

## 💻 পিসিতে চালানো
```bash
# যেকোনো ব্রাউজারে index.html খুলুন, বা:
python3 -m http.server 8000
# তারপর http://localhost:8000 এ যান
```
